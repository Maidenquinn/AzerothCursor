# 🎯 AZEROTH CURSOR — 1.2.0
**Optional class crest on your cursor. Marker and icon, together or alone.**

Huge thanks to **Joker / Kohrinthian** for the class icon masks in [PR #2](https://github.com/Maidenquinn/AzerothCursor/pull/2) — this release builds on that contribution! ❤️

🗡️ **OPTIONAL CLASS ICON**
• Toggle **Class icon** / **Icône de classe** — **off by default**.
• Icon only, ring marker only, or both at once.
• All nine classes, including Rogue / Voleur.
• White circular masks tint with your marker color; dedicated size slider.
• With the icon on, class buttons also pick which crest to show.

🎲 **RANDOM + POLISH**
• **Random** / **Aléatoire** (or `/azcursor random`): marker stays on, everything else rolls.
• Live overlay while options are open.
• Preview matches the real cursor proportions.

⚙️ Open settings with the **cyan minimap button** or `/azcursor`.
