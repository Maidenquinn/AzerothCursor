# 🎯 AZEROTH CURSOR — 1.1.0
**Your class color. Your cursor. A better minimap shortcut.**

This update brings two community-requested improvements, thanks to **Joker / Kohrinthian** and his first contribution! ❤️

🎨 **CLASS COLORS IN ONE CLICK**
• Your current class appears at the top of the color shortcuts.
• All eight other classes are available too — pick whichever color you like!
• Selecting a class color applies it and automatically enables the marker.
• Class labels follow your French/English language choice.

🗺️ **MINIMAP IMPROVEMENTS**
• Support for square minimaps, including KeijinUI.
• The shortcut sits outside the map's edge, including on rectangular layouts.
• Better handling of UI scaling, resizing and delayed minimap styling.
• Your saved position is restored when entering the world.
• Compatibility with collectors that move addon buttons into a drawer.

🛠️ Also includes safer handling of missing class/shape data and layout adjustments around the new class buttons.

⚙️ Open settings with the **cyan minimap button** or `/azcursor`.
